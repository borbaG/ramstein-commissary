RAMSTEIN COMMISSARY ROUTE - FIRST PROTOTYPE

1. Extract the ZIP file to a folder on your Windows PC.
2. Open that folder in File Explorer.
3. Click the address bar, type cmd, and press Enter.
4. In the Command Prompt, run: py -m http.server 8000
5. Open Chrome and visit: http://localhost:8000
6. Click "Load example" or paste your own grocery list, then click "Organize by aisle".

Leave the Command Prompt open while using the prototype. Press Ctrl+C to stop it.
If "py" isn't recognized, Python isn't installed; tell ChatGPT and we'll choose another method.

WHAT THIS VERSION DOES
- Uses the 10,168-product catalog downloaded from the Ramstein Commissary.
- Accepts Apple Notes checkbox list text.
- Splits regular/spicy chicken patties and green/brown ramen with quantities.
- Suggests aisles and groups results in catalog walking order.
- Allows manual aisle corrections and checkboxes.
- Saves the current list in this browser on this PC.

NOT YET INCLUDED
- Shared lists, account sign-in, live phone sync, hosting, and offline phone install.
- Live inventory or price updates.
- Advanced language understanding and confirmed exact-match reliability.

WARNING: Suggestions are heuristic. Verify uncertain locations before relying on them.
